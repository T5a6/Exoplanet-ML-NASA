# 🪐 A World Away — Exoplanet Discovery with AI

### NASA Space Apps Challenge 2025 | Machine Learning & Scientific Data Analysis

**Can machine learning help us discover and understand worlds beyond our solar system?**

Developed for NASA's *A World Away: Hunting for Exoplanets with AI* challenge, this project combines astronomical research, machine learning, and interactive data visualization to analyze NASA exoplanet datasets and explore potentially Earth-like planetary candidates.

Rather than building only a prediction model, we developed an **end-to-end research platform** connecting scientific data, ML experimentation, planetary analysis, and interactive exploration.

---

## 🎯 The Challenge & Our Solution

NASA's astronomical datasets contain thousands of planetary observations with complex scientific characteristics. Analyzing this information requires extensive data preparation, scientific understanding, and reliable classification methods.

Our solution brings together:

- **Scientific feature research:** Studying astronomical equations, detection methods, and planetary characteristics to guide model development.
- **Machine learning:** Training and comparing multiple models to analyze exoplanet observations and classification patterns.
- **Earth-like candidate exploration:** Investigating planetary size, temperature, orbital distance, and other relevant characteristics.
- **Interactive research platform:** Making scientific results accessible through searchable datasets, filters, predictions, and advanced visualizations.

## 🤖 Machine Learning & Technical Development

The project involved preparing NASA datasets, investigating scientifically relevant features, and experimenting with multiple machine-learning approaches.

**Models explored:** Linear Regression, KNN, Decision Tree, Random Forest, and Gradient Boosting.

Our experimentation focused on:

- Comparing model behavior and evaluating results.
- Testing different feature combinations and refining inputs.
- Analyzing feature importance and planetary data distributions.
- Connecting model outputs to meaningful scientific analysis.

The project also extended into **potentially Earth-like candidate exploration**, using characteristics such as planetary radius, estimated temperature, orbital properties, and stellar energy.

## 🖥️ Interactive Platform

The final platform makes the underlying scientific work accessible beyond notebooks and model outputs.

| Feature | Functionality |
|---|---|

| Earth-Like Analysis | Visualize planetary characteristics associated with potentially Earth-like conditions |
| Scientific Visualizations | Examine relationships through interactive charts and 3D views |
| Scientific Information | Explore exoplanet concepts, properties, and detection methods |

## 🚀 Outcome & Key Highlights

Developed during the **two-day NASA Space Apps Challenge 2025**, the project progressed from scientific research and raw astronomical data into an integrated ML and visualization prototype.

**What makes this project distinctive:**

- Combined scientific domain research with practical machine-learning development.
- Explored multiple algorithms rather than relying on a single model.
- Extended analysis beyond classification to potentially Earth-like planetary characteristics.
- Connected technical ML outputs to an interactive research platform.
- Brought together data analysis, ML experimentation, visualization, and team integration within a limited development period.

The result is a research-oriented prototype that makes complex exoplanet information easier to investigate and explore.
